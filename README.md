# ⚡ eKart — Modern Full-Stack E-Commerce Platform

A production-ready, neo-futuristic e-commerce application engineered with the MERN stack. Designed with a high-performance dark glassmorphism aesthetic, dynamic product discovery algorithms, and a seamless shopping experience.

---

### ✨ Key Differentiators

* 🎯 **Behavioral Feed & Discovery Engine:** Real-time user event logging (`views`, `searches`) feeding personalized recommendation rails alongside *Fresh Drops* and *Trending* categories.
* 🇮🇳 **Multi-Currency Engine (`Intl.NumberFormat`):** Instant client-side currency switching (INR ₹ / USD $) tailored with localized Indian digit grouping conventions.
* 🔍 **Multi-Attribute Search & Dynamic Filtering:** Debounced regex search across titles, descriptions, and categories with real-time URL query parameter sync.
* 🛍️ **Interactive Slide-Over Cart:** Persistent localStorage state management, quantity threshold controls, and comprehensive bill breakdown (Subtotal, GST, Free Delivery).
* ⚡ **Neo-Futuristic UI:** Built using Tailwind CSS and Framer Motion featuring ambient glow effects, responsive product galleries, and sticky CTAs.

---

### 🛠️ Tech Stack

* **Frontend:** React (Vite), Tailwind CSS, Framer Motion, React Router v6, Lucide Icons
* **Backend:** Node.js, Express.js, JWT Authentication
* **Database:** MongoDB Atlas (Mongoose ODM)
* **Deployment:** Vercel (Client) + Render (API)
